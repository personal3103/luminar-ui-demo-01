# Development & Automation Scripts

Thư mục này chứa các file script Python được sử dụng trong quá trình phát triển, migrate và tối ưu hóa dự án Lumina Client.

- **Mục đích:** Lưu trữ các công cụ tự động hóa, chuyển đổi dữ liệu, cấu trúc layout và hỗ trợ scaffold/refactor.
- Không ảnh hưởng trực tiếp đến runtime của ứng dụng React/Vite.
